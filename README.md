This project performs EDA on the IMDb Top 1000 Movies dataset, exploring relationships between genres, directors, actors, and IMDb ratings to uncover insights into cinematic success.

Using Python and Pandas, we analyze the top-rated movies to understand trends in popular genres and how elements like runtime and critics' scores influence viewer ratings.

Analyze Movie Success Factors: Investigate which elements (director, genre, cast, plot, duration) correlate with high IMDb ratings and commercial success.

Predict IMDb Scores: Use machine learning to predict a movie's rating based on its attributes.

Explore Industry Trends: Identify patterns in popular genres, popular actors, or changes in movie characteristics over time.

Datasets: Often use scraped data like "IMDb Top 250" or broader "IMDb Movies Data".
Key Features: Title, Rank, Description/Plot, Genre, Director, Actors, Year, Runtime, IMDb Rating, Metascore, Votes, Gross Earnings. 

Tools Used:
Python (Pandas, Matplotlib, Seaborn)
Jupyter Notebooks
